# RegisterPro:

Manual de Usuario del Software RegisterPro
Introducción

El software RegisterPro es una aplicación de caja registradora y gestión de productos diseñada para facilitar la administración de ventas y productos en un entorno comercial. Este manual proporciona una guía detallada sobre cómo utilizar las diferentes funcionalidades del software, desde la gestión de productos hasta la generación de facturas.
Requisitos del Sistema

    Sistema operativo: Windows, macOS, Linux

    Python 3.x instalado (opcional si se utiliza el ejecutable)

    Biblioteca Tkinter instalada (incluida en la instalación de Python)

    Acceso a una base de datos SQLite

Instalación

    Descargar el Instalador: Obtén el archivo ejecutable RegisterPro.exe desde el enlace proporcionado.

    Ejecutar el Instalador: Haz doble clic en el archivo RegisterPro.exe para iniciar la instalación.

    Seguir las Instrucciones: Sigue las instrucciones en pantalla para completar la instalación.

Funcionalidades del Software
1. Login y Registro
Login

    Usuario: Ingresa tu nombre de usuario.

    Contraseña: Ingresa tu contraseña.

    Botón Login: Haz clic en el botón "Login" para acceder al sistema.

Registro

    Usuario: Ingresa un nombre de usuario único.

    Contraseña: Ingresa una contraseña segura (mínimo 8 caracteres).

    Tipo de Usuario: Selecciona el tipo de usuario (Usuario o Admin).

    Botón Registrar: Haz clic en el botón "Registrar" para crear una nueva cuenta.

Recuperar Cuenta

    Usuario: Ingresa el nombre de usuario asociado a la cuenta.

    Nueva Contraseña: Ingresa una nueva contraseña.

    Botón Recuperar: Haz clic en el botón "Recuperar" para restablecer la contraseña.

2. Gestión de Productos
Agregar Producto

    Código de Barras: Ingresa el código de barras del producto.

    Producto: Ingresa el nombre del producto.

    Cantidad: Ingresa la cantidad disponible del producto.

    Precio: Ingresa el precio del producto.

    Botón Agregar Producto: Haz clic en el botón "Agregar Producto" para añadir el producto a la base de datos.

Actualizar Producto

    Seleccionar Producto: Selecciona el producto de la lista.

    Modificar Campos: Actualiza la información del producto (nombre, cantidad, precio).

    Botón Actualizar Producto: Haz clic en el botón "Actualizar Producto" para guardar los cambios.

Eliminar Producto

    Seleccionar Producto: Selecciona el producto de la lista.

    Botón Eliminar Producto: Haz clic en el botón "Eliminar Producto" para remover el producto de la base de datos.

3. Caja Registradora
Agregar Producto a la Venta

    Código de Barras: Ingresa el código de barras del producto.

    Producto: El nombre del producto se autocompletará.

    Cantidad: Ingresa la cantidad del producto.

    Botón Agregar Producto: Haz clic en el botón "Agregar Producto" para añadir el producto a la venta.

Generar Factura

    Total General: El total de la venta se muestra en la parte inferior.

    Pago del Cliente: Ingresa el monto pagado por el cliente.

    Botón Generar Factura: Haz clic en el botón "Generar Factura" para imprimir la factura.

Imprimir Factura

    Botón Imprimir Factura: Haz clic en el botón "Imprimir Factura" para abrir el archivo de la factura generada.

4. Configuración de la Empresa

    Nombre de la Empresa: Ingresa el nombre de la empresa.

    Dirección: Ingresa la dirección de la empresa.

    Teléfono: Ingresa el número de teléfono de la empresa.

    Email: Ingresa el correo electrónico de la empresa.

    Botón Guardar Configuración: Haz clic en el botón "Guardar Configuración" para guardar los cambios.

Conclusión

El software RegisterPro ofrece una solución completa para la gestión de productos y ventas en un entorno comercial. Siguiendo este manual, los usuarios podrán aprovechar al máximo las funcionalidades del software, mejorando la eficiencia y la experiencia del cliente.
